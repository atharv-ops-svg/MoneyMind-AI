# MoneyMind AI

An intelligent personal finance management platform.

MoneyMind AI is a personal finance project designed to help users manage, understand, and organize their finances through accessible digital tools.

The project contains two separate components: a desktop application and a website.

## Getting Started

### Desktop Application

    cd app
    npm install
    npm run app:dev

### Website

    cd website
    pip install -r requirements.txt
    python backend.py
