# MoneyMind AI — Website

The MoneyMind AI website is the web-based component of the MoneyMind AI project.

It is maintained separately from the Electron desktop application.

## Technology Stack

- HTML — Page structure
- CSS — Styling and layout
- JavaScript — Frontend functionality
- Python — Backend functionality

## Project Structure

    website/
    ├── index.html
    ├── styles.css
    ├── app.js
    ├── backend.py
    ├── requirements.txt
    └── README.md

## Installation

Make sure Python and pip are installed.

Navigate to the website directory:

    cd website

Install the required dependencies:

    pip install -r requirements.txt

## Running the Backend

Run:

    python backend.py

The backend will start according to its configured host and port.

## Frontend

The website frontend consists of:

- `index.html` — Main webpage
- `styles.css` — Website styling
- `app.js` — Client-side functionality

## Development

The website is maintained as a separate component of MoneyMind AI.

Its structure and functionality may evolve during development.
